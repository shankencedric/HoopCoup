# 🏀 HoopCoup

**Gameplay Programming • Custom Physics • Clean Architecture**

A first-person basketball shooting prototype built in Unity as a personal 12-hour game jam focused on gameplay engineering, modular architecture, and custom physics systems.

While the gameplay is intentionally simple—pick up a basketball, aim, and shoot—the real goal of the project was exploring how maintainable, decoupled systems can make gameplay features easier to build, extend, and modify.

## 🏗️ The Technical Challenge

HoopCoup began as an experiment in gameplay architecture.

The original concept was to demonstrate how modular systems could allow the player and the basketball to seamlessly exchange responsibilities and controls at runtime. Rather than relying on rigid inheritance chains or tightly coupled logic, the project was designed around composition, interfaces, and clear separation of concerns.

Although the prototype evolved during development and the role-swapping mechanic was never fully realized, the architecture remains the central focus of the project.

### Principles Explored

- Composition over inheritance
- Event-driven communication
- Interface-driven movement systems
- Custom motor abstractions
- Decoupled input and gameplay logic
- Config-driven tuning through ScriptableObjects
