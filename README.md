# HoopCoup
HoopCoup is a personal 12-hour game jam focused on clean code architecture and custom physics implementation. Devoid of everything game feel and design, it is simply a basketball shooter, but for once this time: what matters foremost is *how* it works, not that it does.

## Why the Name
The original game idea was to showcase the modularity and cleanliness of the code by switching the player and the ball's functionalities and controls. Don't worry, I wasn't planning to just swap their visuals and nothing else. The goal was to seamlessly show the flexibility of the code (as it afforded and made to) by the ease of modifying runtime logic and switching roles -- in other words, some sort of a coup.

## Why Make
While it was originally created for my technical exam for CurlyBlue, supposedly featuring game feel, the project beautifully derailed to what it is today.
